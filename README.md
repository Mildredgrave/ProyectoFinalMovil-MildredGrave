# MyGlow - Plataforma de E-commerce de Cosméticos Coreanos

**Skincare e-commerce platform con recomendaciones personalizadas y catálogo de productos coreanos**

---

## 📚 Documentación

- **[DOCUMENTACION.md](DOCUMENTACION.md)** - Guía completa (tecnología, funcionamiento, usuario)

---

## 🎯 Características

- ✅ Catálogo de productos skincare coreanos
- ✅ Sistema de autenticación usuario/admin
- ✅ Quiz inteligente para recomendaciones personalizadas
- ✅ Carrito de compras con persistencia
- ✅ Acordeones interactivos con instrucciones y beneficios
- ✅ Panel administrativo para gestión de productos y pedidos
- ✅ Base de datos en tiempo real con Firebase/Firestore
- ✅ Diseño responsive mobile-first
- ✅ PWA (Progressive Web App)

---

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build
```

Abre: http://localhost:5173

---

## 🏗️ Stack Tecnológico

- **React 19** + **TypeScript 6** - UI moderna y tipada
- **Vite 8** - Bundler ultra-rápido
- **Tailwind CSS 4** + **DaisyUI 5** - Estilos y componentes
- **Firebase 12** - Backend y base de datos
- **PWA** - Instalable como aplicación

---

## 👨‍💻 Desarrollo

### Estructura
```
src/
├── domain/        # Modelos de datos
├── infraestructure/  # Servicios Firebase
└── ui/           # Componentes React
```

### Comandos
```bash
npm run dev      # Desarrollo
npm run build    # Build production
npm run lint     # Linting
npm run preview  # Preview build
```

## 💡 Cómo Usar

**Como Usuario:**
1. Registrarse o iniciar sesión
2. Explorar catálogo y hacer quiz
3. Agregar productos al carrito
4. Completar compra

**Como Admin:**
1. Acceder con rol admin
2. Ir a panel de administración
3. Crear/editar/eliminar productos
4. Gestionar pedidos
